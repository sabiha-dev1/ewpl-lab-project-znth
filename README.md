# ZnthHost - Web Hosting Business Landing Page

ZnthHost is a modern, responsive, single-page web hosting and cloud infrastructure company landing website. Built as a university E-Commerce and Web Programming academic project, it features a premium dark theme and a fully simulated purchase and checkout workflow utilizing a mock bKash payment portal.

## 🚀 Key Features

*   **Premium Dark UI/UX:** Responsive cards, sticky glassmorphism navigation, and custom gradients.
*   **Virtual Server Illustration:** Floating micro-animated graphics representing live CPU, RAM, and SSD storage.
*   **Dynamic Scroll Effects:** Fade-in-up animations and statistics counters that increment when scrolled into view.
*   **Interactive FAQ:** Smooth accordion-style expand and collapse transitions.
*   **bKash Payment Simulation:** Complete modal-driven checkout flow:
    1.  *Plan Selection:* Click "Buy Now" on any hosting tier.
    2.  *Billing Form:* input name, email, and phone contact.
    3.  *bKash Terminal:* Authenticate securely with mock credentials.
    4.  *Loading Screen:* Simulates 2.5-second bank verification.
    5.  *Success Receipt:* Generates a unique, randomized Transaction ID.

## 🛠️ Built With

*   **HTML5** - Semantic structure
*   **CSS3** - Custom variables, responsive grid/flexbox layouts, keyframe animations
*   **Vanilla JavaScript** - IntersectionObserver API, modal state machine, dynamic counters
*   **Icons & Fonts** - FontAwesome v6, Google Fonts (Outfit & Inter)

## 💻 How to Run

1.  Clone this repository to your local machine:
    ```bash
    git clone https://github.com/sabiha-dev1/ewpl-lab-project-znth.git
    ```
2.  Open `index.html` directly in any modern web browser, or launch it with a local development server extension (e.g., Live Server in VS Code).
